# **Libft**

### Description
This is my custom C library containing re-implementations of standard C functions and additional utilities. This project serves as a foundation for future C projects in the 42 curriculum.

### Instructions
Clone the repository and enter the directory:
```bash
git clone https://github.com/JokoN3/libft.git
cd libft
```
Run make:
```
make
```

Include libft.h in your code:
```
#include "libft.h"
```

and finally compile libft.a along with your files:
```
cc project_name.c libft.a -o project_name
```
